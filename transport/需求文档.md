# transport 子系统 — 需求文档（Requirements）

> 版本：v2
> 日期：2026-08-12
> 范围：`d:/code/lulu-bootstrap/transport`（传输层适配层 / server builders）

---

## 1. 背景与目标

`transport` 子系统将 `conf.BootstrapConfig.Server` 声明的传输层配置，构建为可运行的 `transport.Server` 实例并注册到框架。

v2 仅内置 **HTTP** 一种传输层（`transport/http`），支持声明式中间件与命令式路由注册。

每个适配为独立子包，通过 `init()` 自注册到 `bootstrap.MustRegisterServerBuilder`。

---

## 2. 功能需求

### FR-1 服务器构建注册
- **FR-1.1** `transport/http` 包 `init()` 调 `bootstrap.MustRegisterServerBuilder(bootstrap.ServerTypeHTTP, newBuilder)`。
- **FR-1.2** `newBuilder(cfg *v1.Server) (transport.Server, error)` 返回服务器实例。

### FR-2 HTTP 服务器构建（http）
- **FR-2.1** 取 `cfg.GetHttp()`；空返回 "http: config is nil"。
- **FR-2.2** `addr` 缺省 `:8080`。
- **FR-2.3** 默认使用内置 **std Driver**（基于 `net/http` 标准库，`http.ServeMux`）。
- **FR-2.4** 声明式中间件（见 FR-3）按 proto 字段顺序注册；命令式 setup 回调（见 FR-4）随后调用。

### FR-3 声明式中间件
按 proto 字段号顺序（`Server_Http_Middleware`）：
1. **Recovery**：`stack_trace`(bool)。
2. **CORS**：`allowed_origins`/`allowed_methods`/`allowed_headers`/`exposed_headers`/`allow_credentials`/`max_age`。
3. **Logging**：`skip_paths`。
4. **RequestID**：`header_name`（空则用默认）。
5. **Tracing**：复用全局 TracerProvider（无参数）。
6. **RateLimit**：`rate`+`burst` 构造 tokenbucket 限流器；`wait`(bool) 决定超限后等待还是拒绝。
7. **Timeout**：`default_timeout_ms`（缺省 5000ms）。

### FR-4 命令式路由/中间件注册
- **FR-4.1** `RegisterServerSetup(fn func(srv *Server))`：追加式注册回调，在服务器创建后、返回框架前依次调用，用于注册路由（`srv.GET` 等）与额外 `srv.Use` 中间件。
- **FR-4.2** `SetServerSetup(fn)`：替换式（仅保留 fn），已标记 Deprecated，建议使用 `RegisterServerSetup`。
- **FR-4.3** `Server` 类型别名：`type Server = httpPlugin.Server`，业务与代码生成器只依赖本适配包，不直接依赖 `lulu-ext`。

### FR-5 多传输层
- **FR-5.1** v2 仅 HTTP；其他传输层（gRPC 等）暂未实现适配。

---

## 3. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | **零侵入启用**：匿名导入即注册。 |
| NFR-2 | **自注册**：`init()` 机制。 |
| NFR-3 | **声明 + 命令双模**：proto 控制中间件，代码注册路由。 |
| NFR-4 | **与 conf 对齐**：读取 `v1.Server` 生成代码。 |
| NFR-5 | **可扩展驱动**：Server 构造接受 `WithDriver`，内置 std，可替换 chi/gin/fiber。 |
| NFR-6 | **优雅关闭**：std Driver 的 Start/Stop 支持 ctx 取消与 `Shutdown`。 |

## 4. 目录结构

```
transport/
└── http/
    └── http.go    # HTTP 适配 + std Driver + 中间件注册 + Setup 回调
```

---

## 5. 验收标准

1. `import _ ".../transport/http"` 后，`Server.Http` 能构建监听 `:8080` 的 HTTP 服务器。
2. 配置的中间件按声明顺序生效（Recovery→CORS→Logging→RequestID→Tracing→RateLimit→Timeout）。
3. 业务经 `RegisterServerSetup` 注册的路由可被访问。
4. 应用关闭时服务器优雅停止（ctx 取消触发 `http.Server.Shutdown`）。

---

## 6. 风险与假设

- **假设**：v2 仅 HTTP；gRPC/GraphQL/WebSocket 等传输层暂无适配。
- **风险**：内置 std Driver 仅实现基础 `Handle`（方法不匹配返回 405），复杂路由能力依赖 `lulu-ext` 的 chi/gin/fiber Driver。
- **注意**：`ServerTypeHTTP` 与 conf 扩展名 `http` 一致；多 HTTP 实例场景需框架支持按名索引。
