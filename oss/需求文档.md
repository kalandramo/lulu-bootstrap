# oss 子系统 — 需求文档（Requirements）

> 版本：v2
> 日期：2026-08-12
> 范围：`d:/code/lulu-bootstrap/oss`（对象存储适配层 / storage builders）

---

## 1. 背景与目标

`oss` 子系统将 `conf.BootstrapConfig.Storage` 声明对象存储配置，构建为可用的对象存储客户端，并登记到运行期 `Context.Storage(name)`。

v2 内置两种适配：
- **MinIO**（经 `lulu-ext/oss/minio`）
- **S3**（S3 兼容，经 `lulu-ext/oss/s3`）

每适配为独立子包，通过 `init()` 自注册到 `bootstrap.MustRegisterStorageBuilder`。

---

## 2. 功能需求

### FR-1 存储构建注册
- **FR-1.1** 每子包 `init()` 调 `bootstrap.MustRegisterStorageBuilder(typeKey, newBuilder)`。
- **FR-1.2** `typeKey` 对应 `types.go` 的 `StorageTypeMinio` / `StorageTypeS3`。
- **FR-1.3** `newBuilder(ctx, *v1.Storage) (any, func(), error)` 返回实例 + cleanup。

### FR-2 MinIO 适配（minio）
- **FR-2.1** 取 `cfg.GetMinio()`；空返回 "minio: config is nil"。
- **FR-2.2** 映射 `minioPlugin.Config`：`endpoint`/`access_key`/`secret_key`/`token`/`use_ssl`。
- **FR-2.3** `minioPlugin.NewStorage(pluginCfg)`；返回 nil 时返回 "minio: failed to create storage"。
- **FR-2.4** 当前 cleanup 为空函数。

### FR-3 S3 适配（s3）
- **FR-3.1** 取 `cfg.GetS3()`；空返回 "s3: config is nil"。
- **FR-3.2** 映射 `s3Plugin.Config`：`endpoint`/`region`/`access_key`/`secret_key`/`token`/`use_ssl`/`force_path_style`/`bucket`。
- **FR-3.3** `s3Plugin.NewClient(pluginCfg)`；返回 nil 时返回 "s3: failed to create client"。
- **FR-3.4** 当前 cleanup 为空函数。

### FR-4 多实例管理
- **FR-4.1** 多个 `optional` 存储可在同一 `Storage` 并存。
- **FR-4.2** 实例存入 `Context.storages` map（按类型名索引），业务经 `Context.Storage(name)` 取用（返回 `any`，需类型断言）。

---

## 3. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | **零侵入启用**：匿名导入子包即注册。 |
| NFR-2 | **自注册**：`init()` 机制。 |
| NFR-3 | **与 conf 对齐**：读取 `v1.Storage` 生成代码。 |
| NFR-4 | **隔离依赖**：minio / s3 子包独立，互不影响。 |
| NFR-5 | **统一返回**：返回 `any`，由 Context 聚合。 |

---

## 4. 目录结构

```
oss/
├── minio/minio.go    # MinIO 适配（自注册 StorageTypeMinio）
└── s3/s3.go          # S3 兼容适配（自注册 StorageTypeS3）
```

---

## 5. 验收标准

1. `import _ ".../oss/minio"` 后，`Storage.Minio` 能构建 MinIO 客户端。
2. `import _ ".../oss/s3"` 后，`Storage.S3` 能构建 S3 兼容客户端（含 force_path_style / bucket）。
3. `Context.Storage("minio")` / `Context.Storage("s3")` 可取回对应实例。

---

## 6. 风险与假设

- **假设**：v2 仅 minio + s3；conf 中无其他存储类型。
- **注意**：两适配 cleanup 均为空函数；MinIO/S3 SDK 的连接回收依赖进程退出或插件内部机制。
- **注意**：`lulu-ext/oss/*` 为外部插件依赖，本子系统仅做配置桥接。
